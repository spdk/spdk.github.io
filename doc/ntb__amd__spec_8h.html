Detailed Description

AMD NTB specification / on-the-wire protocol definitions.

This header is intentionally split out of include/spdk/ntb_amd.h so that consumers of the public driver API don't have to pull in the register layout, while applications that participate in the peer-to-peer scratchpad handshake (e.g. examples/ntb/perf) can.

Enumeration Type Documentation

◆ spdk_ntb_spad_idx

enum spdk_ntb_spad_idx

Layout of the peer-to-peer handshake scratchpad block.

Both sides agree on these indices when publishing / consuming the memory-window configuration via the scratchpad registers. Index 0 is intentionally reserved (the AMD NTB hardware itself uses spad[0] for peer-discovery interlock).

Only the memory-window count is exchanged: the actual address translation is programmed directly into the peer's XLAT registers by ntb_amd_mw_set_trans(), so there is no need to publish per-window base addresses or sizes through the scratchpads.

◆ spdk_ntb_topo

enum spdk_ntb_topo

NTB topology assignment, as exchanged over the link and returned by spdk_ntb_amd_attr_get(SPDK_NTB_TOPO_NAME).

One side comes up as primary (PRI), the other as secondary (SEC); the AMD NTB exposes this through bit 0 of the side-info register and the driver caches it here.
