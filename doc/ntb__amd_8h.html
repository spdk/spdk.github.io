◆ spdk_ntb_amd_get_peer_mw()

int spdk_ntb_amd_get_peer_mw ( struct spdk_ntb_amd_dev * ntb,
uint8_t mw_idx,
struct iovec * iov,
struct spdk_memory_domain ** domain,
void ** vaddr )

Describe a peer memory window as a DMA target.

Fills iov with the window's device (bus) address (iov_base) and size (iov_len), and domain with the NTB device memory domain. The (iovec, memory-domain) pair can be passed directly to spdk_ae4dma_build_copy() as a copy endpoint: because the domain is non-NULL and describes device memory, the engine treats iov_base as an already-resolved bus address (no spdk_vtophys()) and as IO memory.

For CPU access to the same window (e.g. memcpy), vaddr optionally receives the locally-mapped virtual address.

Parameters
ntbNTB channel handle returned by spdk_ntb_amd_probe().
mw_idxMemory window index, less than the memory-window count.
iovOutput iovec describing the window (bus address + size).
domainOutput NTB memory domain for the window. May be NULL.
vaddrOptional output for the locally-mapped virtual address. May be NULL if the caller only needs the DMA view.
Returns
0 on success, -EINVAL on invalid arguments, -ENODEV if the window is not mapped.

◆ spdk_ntb_amd_handshake_work()

int spdk_ntb_amd_handshake_work ( struct spdk_ntb_amd_dev * ntb,
void * buffer,
size_t buffer_size )

Perform the peer-to-peer NTB handshake.

Publishes the memory-window count via scratchpad, programs each memory-window translation to a non-overlapping slice of buffer, and rings doorbell 0 to notify the peer.

Parameters
ntbNTB channel handle returned by spdk_ntb_amd_probe().
bufferLocal DMA-capable staging buffer that backs all exposed memory windows. The buffer must be physically contiguous (e.g. allocated via spdk_dma_zmalloc()) and at least sum(mw_size[i]) bytes long, where mw_size[i] is the size of the i'th memory window. Memory window i is programmed to the slice starting at offset sum(mw_size[0..i-1]).
buffer_sizeSize of buffer in bytes; rejected with -EINVAL if smaller than the sum of memory-window sizes, or if the buffer is not physically contiguous across that range.
Returns
0 on success, negative errno on failure.

◆ spdk_ntb_amd_peer_ready_get()

bool spdk_ntb_amd_peer_ready_get ( const struct spdk_ntb_amd_dev * ntb)

Read the cached "peer ready" flag for this channel.

The flag is true once the local side has observed the peer-ready doorbell at least once and is intended to gate the per-link-up setup (memory-window translations, mempool buffer publication, etc.) so that the application does not redo it for every duplicate doorbell.

The driver itself only reads this flag (it folds it into the value returned for the "link_status" attribute). Updating it is the application's responsibility — see spdk_ntb_amd_peer_ready_set().

Parameters
ntbNTB channel handle returned by spdk_ntb_amd_probe().
Returns
true if the peer is currently considered ready, false otherwise (also returns false if ntb is NULL).

◆ spdk_ntb_amd_probe()

int spdk_ntb_amd_probe ( void * cb_ctx,
spdk_ntb_amd_probe_cb probe_cb,
spdk_ntb_amd_attach_cb attach_cb )

Enumerate the NTB devices attached to the system and attach the userspace NTB driver to them if desired.

If called more than once, only devices that are not already attached to the SPDK NTB driver will be reported.

To stop using the controller and release its associated resources, call spdk_ntb_amd_detach() with the ntb_channel instance returned by this function.

Parameters
cb_ctxOpaque value which will be passed back in cb_ctx parameter of the callbacks.
probe_cbwill be called once per NTB device found in the system.
attach_cbwill be called for devices for which probe_cb returned true once the NTB controller has been attached to the userspace driver.
Returns
0 on success, -1 on failure.
